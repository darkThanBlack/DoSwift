DoSwift · 悬浮窗菜单

主菜单的三个设计方向

现在这套菜单的问题不在配色，在形状——它长成了一个居中弹出的模态面板，而它本该是一个锚在浮窗旁边、能看见底下的调试浮层。下面是三条路线，都在 iOS 13 部署目标上能落地。

推荐方向 B。锚定 + 毛玻璃 + 图标片分组，改动量中等（一个视图控制器 + 一个自绘面板），拿到的是原生质感又不被系统菜单的固定结构框死。如果只想改一天就见效，直接上 A，把菜单交给 UIKit。

现在丑在哪

六条都能在代码里定位到。前三条是形状问题，后三条是细节问题——先修形状，细节才有意义。

菜单跑到屏幕正中央

触发它的浮窗贴在屏幕边缘，菜单却弹在正中，两者失去空间关系。看起来像一个弹错位置的 alert，而不是「从这个按钮长出来的」。

从浮窗旁展开，贴不进就翻转方向 — centerXAnchor / centerYAnchor

遮罩是透明的，点它却会关闭菜单

视觉上不是模态，交互上却是模态。用户看到的是「背景能用」，点下去才发现被当成点击外部关闭了。

要么压暗成真模态，要么不压暗但只关菜单 — backgroundColor = .clear

面板不透明，正好挡住要调试的东西

调试浮层的全部意义是叠在真实界面上，纯色 systemBackground 把它变成了一张报纸。

换成 .systemThickMaterial 模糊材质 — systemBackground

满宽分隔线穿过圆角

四条线从面板最左拉到最右，直接穿过 12pt 圆角。这是全页最明显的粗糙点，也是最好修的。

去掉线，改用间距分组 — separatorStyle = .singleLine

整屏只有一种蓝

每个图标都 tintColor = .systemBlue，浮窗按钮也是同一个 systemBlue。图标不承载任何语义，只是在重复强调色。

图标片按分组配色，或退成次要灰 — iconImageView.tintColor

子菜单是假的

「网络工具」显示了 › 箭头，点下去却直接触发 action——没有任何二级面板。箭头在骗人。

二级项就地缩进展开，或去掉箭头 — arrowImageView.isHidden

四个形态并排

同一份菜单数据（应用信息 / 网络工具 / UI 调试 / 关闭），四种做法。菜单项文字取自 DoSwiftCore.swift 现有内容，浮窗位置固定在同一处，方便对比落点差异。

A · 交给系统菜单

最省力
  • 一次不用自己画。圆角、材质、行高、图标规则、分隔线内缩、进出动画全部由 UIKit 决定，也自动跟随 iOS 版本演进——升级到 iOS 26 时它会自己变成 Liquid Glass。
  • 锚定和翻转由系统处理，浮窗贴近屏幕底部或右缘时会自动朝内展开，这个逻辑自己写通常要写错两遍。
  • 代价是结构被锁死。每行只能是一个符号 + 一行文字，不能塞开关、状态数值、自定义行高；面板宽度和分组留白也不是你说了算。
  • iOS 14 才有 UIButton.menu；部署目标 13.0 要退回 UIContextMenuInteraction，触发方式是长按而非轻点，需要额外接管手势。

B · 锚定毛玻璃面板

推荐
  • 形状对了，其余都好办。菜单从浮窗旁边长出来，浮窗贴左缘就从左边展开，贴底就往上传——空间关系一眼可见。
  • 材质用 .systemThickMaterial，不压暗背景。这是调试浮层该有的姿态：叠在上面，但仍然看得见底下的界面在动。
  • 分组小标题 + 图标片替代满宽分隔线。四个图标片用不同色相区分分组，颜色终于开始承载语义，而不是重复强调色。
  • 二级项就地缩进展开，顺手把「显示箭头但没有二级面板」这个现有缺口补上。
  • 42pt 以下的行高对调试工具仍然偏松，可以降到 44/40 再收紧一档。

C · 高密度工具风

另一条审美
  • 不假装自己是消费品。固定深色、40pt 行高、等宽数字——气质更接近 Xcode 面板或 Lookin，而不是 iOS 设置页。
  • 行尾可以挂实时数值（请求数、视图层数、内存），调试信息从「点进去才看得到」变成「扫一眼就知道」。
  • 固定深色意味着不用维护两套配色，但会和浅色业务界面形成强对比，截图分享时也更醒目。
  • 代价是密度上去了、可读性下来了：中文在 13–14pt 深色底上偏细，需要把字重提到 500 才站得住。

如果选 B，落地顺序

按改动从外到内排，每一步都能单独编译验证——符合这个仓库「每批完成后由你手动编译」的现有节奏。

  1. 先改浮窗按钮

    把 DriftView 里的蓝圆套白圆换成真实图标，按钮改成毛玻璃圆。这一步独立于菜单，改完就能看出区别。

  2. 再改定位

    DoSwiftMenuViewController 去掉 centerX/centerY，改为读浮窗 frame 计算锚点，并处理贴边翻转。同时把那个透明遮罩去掉。

  3. 然后换材质和圆角

    面板换成 UIVisualEffectView，圆角提到 16 并开 continuous，去掉 separatorStyle。

  4. 最后补结构和按压缩放

    加分组小标题、图标片配色、二级项缩进展开，退出前跑一遍深浅色和 SE/iPad 两种尺寸。
