# DoSwift





## Intro

[DoKit](https://github.com/didi/DoKit) 前身为 DoraemonKit，原为滴滴 iOS 端位内部使用的本地调试工具。

后来得到内部支持，开始往各端位横向扩展，并接入所谓平台功能。

截至 2025 年，注意到主仓库已进入彻底无效的状态，使用个人 PR [DoKit-iOS](https://github.com/darkThanBlack/DoKit-iOS) 进行最低限度的可用性维护。

本工程是基于 Swift，借助 AI 能力，由我个人推进的彻底重写。



## Feature

#### Mainly

* [x] 从头开发，基于 iOS 13 SF Symbol 的全新 UI

#### UI Hierarchy

* [x] 将原有的视觉工具能力全部整合成一个
  * [x] 取色计 / 组件检查 / 对齐标尺 / 布局边框 / UI 结构

* [x] 彻底修复 view 查找逻辑，浮窗不阻拦主 APP 操作
* [x] 删除大量模板代码
  * 原版为每个属性做了 OC 合成，改为通过 json 渲染
  * 通过尽量实现：移除自定义文本，value 类型推导，简化 OC 枚举声明表 等操作减少代码长度，增加可读性
* [ ] 实时修改对象属性值
  * [ ] 编辑 UI 重新设计
  * [ ] 暂不允许编辑布局类属性（frame / center / layer.*），需要额外处理约束相关属性的展示和编辑

* [ ] 父子节点展示与切换交互需要重新设计
* [ ] 具体字段需要逐一检查并补强

#### 性能

* [x] 将原有的性能工具能力全部整合成一个
  * [x] （取色计 / 组件检查 / 对齐标尺 / 布局边框 / UI 结构）

* [x] 指标即数据源：加一个指标 = 往列表里加一行，不再是一种窗口/页面/开关
  * 第一个：帧率 / CPU / 内存（流量待网络拦截器落地）
* [x] **数据层与 UI 层分离**
  * 数据层：每个指标自己定采样间隔、自己存不裁剪的 `(时刻, 值)` 序列，不做聚合
  * UI 层：只做一件事——给一个时间区间，取出一列点，自行计算和绘制
* [x] 两种展示形式并存，设置页可选、选择持久化，**读的是同一批序列**
  * 折线图 112 × 66：一条指标、30 秒窗口、阈值虚线
  * 单行文字：`FPS 60 · CPU 3% · 内存 413 MB`，一次显示全部
* [x] 三个源**各自驱动、互不共享时钟**，采集方式照 Firebase：
  * CPU —— 私有串行队列 + `dispatch_source`(100ms) + `task_basic_info` 累计时间差分
  * 内存 —— 私有串行队列 + `dispatch_source`(100ms) + `mstats()`
  * 帧率 —— 主线程 `CADisplayLink`，逐帧量间隔，慢帧/冻结帧阈值按屏幕刷新率算
  * 序列**只在主线程写、只在主线程读**，不需要锁
* [x] 刷新节奏归展示形式：折线 10Hz、单行文字 1Hz（数字一秒跳十次读不了）
* [x] 断档判定在数据层（`segments(from:to:gap:)` 返回若干段），「断开画」在 UI
* [ ] 内存量程改自校准（等 `os_proc_available_memory()` 作为新字段叠上来）
* [x] 单击换指标、长按回设置页、拖动吸边并记忆位置
* [ ] 完整折线图页（读同一份序列，按像素列取 min/max 画竖线）
* [ ] 其余性能工具（Crash / 卡顿 / 启动耗时 / 大图 / 泄漏 / 弱网…）落到这一页里

#### 自定义插件

* [x] 业务实现 `DoSwiftPlugin`，交给 `DoSwiftCore.start(appWindow:plugins:)` 就多一个菜单入口
  * 窗口 / 层级 / 导航栈 / 关闭按钮由 `DoSwiftPluginHost` 提供，形态与内建工具一致：
    一个插件一个 `OverlayWindow`（`.alert - 1`），注册进主菜单的「自定义」分组
  * 页面**每次点开现造**（`makeViewController(host:)`），读到的永远是当下状态，不需要刷新协议
  * 页面做完该走的事（切完环境、保存成功…）调 `host.hide()` 收掉自己

#### App 信息

* [x] 内建四组字段；四个域对象各管自己那一摊，页面只跟 `AppInfo` 打交道
  （值一律是可空的存储属性，开页 `reload()` 统一赋值 —— 同步与异步因此是同一个形状）
  * 设备：机型与机器码 / 系统版本与构建号 / 屏幕（点·像素·刷新率）/ IPv4 / IPv6
    / 设备名称（iOS 16 起系统恒给机型号，此时不占行）
  * 应用：Bundle ID / Version / Build / 显示名 / 构建配置 / 分发渠道 / 运行形态 / 可执行文件时间
  * 运行时：当前页面 / 语言与地区 / 时区 / 热状态 / 低电量模式 / 设备标识
  * 权限：定位 / 通知 / 相机 / 麦克风 / 相册 / 通讯录 / 日历 / 提醒事项 / 蓝牙 / 跟踪 / 蜂窝数据
* [x] 权限一律**只读不请求**（`authorizationStatus` 类查询不弹窗），并补齐现代档位
  （相册 `.limited`、日历 `.writeOnly`、通讯录 iOS 18 `.limited`、麦克风 iOS 17 新口径）
* [x] 点按任意一行复制该行的值；导航栏「复制 JSON」把整页按组序列化进剪贴板
* [x] `AppInfoPlugin.setCustomItems(_:)` 供宿主追加自己的字段（环境域名、推送 regid、公共参数…）
* [x] 异步两项（通知、蜂窝）**统一通知**：值变了响一声，外层不关心是哪个字段、什么时候变
* [ ] 本地网络权限：系统没有查询接口，只能靠 `NWBrowser` 试探，暂不提供
* [ ] 越狱检测 / 磁盘余量
